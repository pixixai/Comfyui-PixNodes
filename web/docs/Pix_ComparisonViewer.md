# 对比查看器

**Comparison Viewer** 在节点内滑动对比图像与视频，支持图像＋图像、视频＋视频、图像＋视频。

## 输入与兼容性

- **前景（F）**：图像或 ComfyUI 标准 `VIDEO` 对象。
- **背景（B）**：图像或 ComfyUI 标准 `VIDEO` 对象。
- 两个输入均可选；只连接一侧时显示该侧内容。
- 图像批次显示 F1、F2、B1、B2 等选择项，按静态图片比较，不自动当作视频播放。帧批次可先通过 ComfyUI 的“创建视频”节点指定帧率并转换为 `VIDEO`。
- 节点注册 ID 为 `Pix_ComparisonViewer`，输入键名为 `foreground_image`、`background_image`。旧工作流若使用 `Pix_ImageComparer`，需要替换为新节点后使用。

## 画面对比

鼠标在画面内左右移动，调整前景与背景之间的分割线。不同尺寸的素材均保持原始比例显示。

在媒体区域按住鼠标中键拖动，可平移 ComfyUI 画布；移出节点后仍可继续拖动，松开中键结束。此操作不改变节点位置、对比分割线或播放状态。

运行成功后按前景素材的尺寸和比例自动调整预览区与节点，较大的素材缩放到 640×480 范围内；仅连接背景时以背景为准。手动缩放节点时，预览区填满节点内部的可用空间，素材等比完整显示。切换批次素材保持手动调整后的节点尺寸。

预览区背景透明，留白区域透出节点本身的底色，适配普通模式与 Nodes 2.0；图片和视频本身保持正常显示。

仅比较图像时，右键菜单的“图像对比模式”可切换“滑动分割”与“按住切换”。视频模式始终使用滑动分割，单击画面控制两侧播放／暂停，没有独立播放按钮。

## 视频控制

视频默认暂停、静音，并启用循环播放。底部保留进度条；鼠标进入预览区域时，进度条上方显示左侧时间码，以及右侧音量和倍速控件。

| 操作区域 | 操作 | 效果 |
| --- | --- | --- |
| 视频画面 | 单击 | 两侧同步播放／暂停 |
| 视频画面 | 滚轮 | 保留 ComfyUI 画布缩放／平移 |
| 视频画面 | Alt＋滚轮 | 与进度条相同：暂停按帧、播放按秒，保留原来的播放／暂停状态 |
| 进度条 | 点击或拖动 | 两侧同步跳转；播放中拖动，松开后继续播放 |
| 进度条 | 滚轮 | 暂停时每格 1 帧、Shift 10 帧；播放时每格 0.5 秒、Shift 1 秒；保留原来的播放／暂停状态 |
| 左下角时间码 | 滚轮 | 与进度条相同：暂停按帧、播放按秒 |
| 左下角时间码 | 单击 | 切换循环播放／单次播放，显示短暂的小字提示；选择会随工作流保存 |
| 音频按钮 | 单击 | 静音／恢复，记住之前的音量 |
| 音频按钮 | 悬停 | 音量滑杆向左展开，可拖动调节 |
| 音频按钮或音量滑杆 | 滚轮 | 每格调整 5% 音量 |
| 倍速数值 | 悬停并滚轮 | 每格调整 0.25 倍速 |
| 倍速数值 | 点击输入 | 输入倍速，按回车或点击外部确认；Esc 取消 |

调整进度时，滚轮向下（向自己方向）前进，向上（向外推）后退。调整音量、倍速时，向上增大、向下减小。鼠标移到滑杆或输入框时，控件保持显示；这些控件的操作不会触发画面播放或画布缩放。触控板的缩放手势保留给画布。

播放时的跳转量按视频时间轴计算，不随帧率或播放倍速改变；例如 2 倍速下，0.5 秒视频内容会在现实中用 0.25 秒播完。跳到共同片段末尾时，循环模式回到开头继续播放，单次模式停在末尾。

两侧按同一时间轴同步。逐帧步进以前景视频帧率为基准；前景是图片时，以背景视频为基准。时长不同的视频仅播放共同时间区间：循环模式到达较短视频结尾时，两侧同时回到开头继续播放；单次模式则同时暂停。

声音默认来自前景视频；只有背景包含音轨时自动使用背景。右键“声音来源”可以切换，任何时刻只播放一路声音。素材没有音轨时不发声，仍可预设音量和静音状态。拖动进度时暂时静音，松开后按之前的状态恢复；暂停时逐帧定位不发声。

## 端口布局与输出

右键“Connections Layout”可选择左右或上下端口布局。该节点没有输出端口，作为工作流终点执行，并在 ComfyUI 临时目录生成预览文件。
